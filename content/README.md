# Contenido editable del sitio Dominues

Edita **solo los archivos de esta carpeta** para cambiar textos legales y preguntas frecuentes.

| Archivo | Página en la web |
|---------|------------------|
| `faq.json` | Preguntas frecuentes (`/faq` y sección en inicio) |
| `privacy.html` | Privacidad (`/privacy`) |
| `terms.html` | Términos y condiciones (`/terms`) |
| `responsible-gambling.html` | Juego responsable (`/responsible-gambling`) |
| `aml.html` | AML (`/aml`) |
| `pages.json` | Títulos de las páginas legales (no borrar claves) |

Guía completa para el cliente: `docs/GUIA-EDITAR-CONTENIDO-DOMINUES.md`
